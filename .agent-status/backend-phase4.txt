FILES CREATED
-------------
sdk/python/auth_client/jwks_cache.py
  - JWKS public key cache with 5-minute TTL and kid-based rotation
  - Uses httpx to fetch JWKS endpoint
  - Module-level cache with monotonic-clock TTL check
  - get_key() auto-refreshes on stale cache or unknown kid
  - invalidate() helper for test isolation

sdk/python/auth_client/validator.py
  - JWT RS256 validator using authlib.jose (NOT python-jose — removed per reviewer)
  - Extracts kid from header without full decode first
  - Fetches public key via jwks_cache.get_key()
  - Verifies signature with JsonWebSignature.deserialize_compact()
  - Checks exp claim manually (int(time.time()) comparison)
  - Checks grants[] array for app_name membership
  - Raises TokenExpiredError, InvalidTokenError, NoGrantError
